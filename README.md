# 潮汐邮局 (Tidal Post)

H5 休闲解谜游戏:控制潮水,让小纸船把信件送到对应码头。
俯视纸艺海港画风,纯前端,无外链资源,可静态托管。

> 当前为 **8 关原型(v0.1.0)**,用于验证核心玩法;最终赛事版本目标 ≥50 关,尚未完成。

## 玩法

- 一个潮向指令(上/右/下/左)同时推动**所有**船各走一格,不滑到底。
- 船进入与自己邮戳一致的码头即完成投递;全部投递完成即过关。
- 船压住浮标时,关联水闸在**本次潮汐**打开——以潮起那一刻的占用为准,中途不变。
- 第 5 关起解锁**潮汐锚**:让一艘船原地留一拍,替队友守住机关。
- 无失败惩罚:走错可无限撤回或重来。

## 操作

| 方式 | 说明 |
| --- | --- |
| 滑动 | 在棋盘上四向滑动(手势结束时提交一次) |
| 按钮 | 右下角四向键 |
| 键盘 | 方向键或 WASD |
| 潮汐锚 | 点「锚」按钮 → 点一艘船 → 选潮向;Esc 取消 |

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发模式(默认 http://localhost:5173)
npm test           # 运行 AC01–AC14 全部测试(69 例)
npm run typecheck  # TypeScript 类型检查
npm run build      # 生产构建到 dist/(相对资源路径,可子目录托管)
npm run preview    # 预览构建产物
```

也可用任意静态 HTTP 服务直接托管 `dist/`(如 `npx serve dist`)。

## 规则要点(TIDE-RULES-1)

- 同步潮汐:所有未锚定的船同向移动一格;前船受阻,跟随的后船同样停住。
- 码头匹配:他人码头(含已交付的)是障碍;进港后船退出棋盘。
- 水闸快照:本次开闭由潮起瞬间浮标占用决定,结算后才更新画面。
- 潮汐锚:只在下一次**有效潮汐**生效;全体不动时不消耗、可继续保留。

完整规则、验收标准与验证证据见 `docs/PRD.md`。
